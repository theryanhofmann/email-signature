Install the Alterra animated email signature

This page copies the rendered signature as rich content for Gmail.

Do not copy or paste the HTML source code. Click the button below, then paste directly into Gmail. You should see the finished visual signature—not code—in Gmail’s editor.
  
Ryan Hofmann
CEO & Creative Director

hofmann@alterra.studio
  1. Click Copy rendered signature.
  2. In Gmail, delete the HTML code currently inside the signature box.
  3. Paste normally with Ctrl+V. Confirm that the visual card appears.
  4. Under Signature defaults, select this signature for new emails and optionally replies/forwards.
  5. Scroll to the bottom and click Save Changes, then open a brand-new compose window.
